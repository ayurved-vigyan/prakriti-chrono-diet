# Prakriti & Chrono-Diet — Free PWA Starter

यह एक zero-cost, no-build-tools starter है।

## इसमें क्या है
- Hindi / English switch
- Light / Pure White / Dark themes
- 6 ऋतुएँ
- Responsive mobile-first UI
- Animated nature hero (lightweight CSS pseudo-3D)
- Interactive Chrono-Diet clock
- 12-question demo analyzer
- Vata/Pitta/Kapha demo scoring
- PWA manifest + service worker
- No paid API
- No database
- No external framework dependency

## अपने computer पर चलाना
सबसे आसान:
1. इस folder को खोलें।
2. `index.html` को browser में खोलें।

PWA install/offline testing के लिए local server बेहतर है:
- VS Code में Live Server extension, या
- Python: `python -m http.server 8080`
फिर browser में `http://localhost:8080` खोलें।

## Free hosting
GitHub Pages पर इस folder की files upload करके free HTTPS URL मिल सकता है।
उदाहरण: `https://USERNAME.github.io/REPOSITORY/`

## महत्वपूर्ण
यह prototype educational wellness experience है, medical diagnosis नहीं।
AI API, database, payments और ads अभी नहीं जोड़े गए हैं।
